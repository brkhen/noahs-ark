# The web prototype

The game was first designed as web prototypes (claude.ai artifacts). They are the design reference for the Godot app: how each mini-game plays, the wording, the colors and the art direction.

| Prototype | Link |
|---|---|
| Story Games (main build, newest) | https://claude.ai/code/artifact/a391eeba-ae68-47a5-8bda-e29d78dab19c |
| Illustration Art Direction Brief | https://claude.ai/code/artifact/d3ce699e-2f67-40b0-a034-23014d0857d6 |
| Memory Match (newer version) | https://claude.ai/code/artifact/281b18fe-71a7-45a2-8124-fc281762d1eb |
| Seek & Find | https://claude.ai/code/artifact/21f4a279-1067-4076-bcce-7b72345eb8d6 |

`story-games.html` is a saved copy of the Story Games build as of 2026-10-17, so the reference stays with the code. Open it in Safari or Chrome to play it. It is never exported into the app (the export presets leave out `docs/`).
