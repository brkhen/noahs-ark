# Fonts

The same three fonts as the web prototype, from Google Fonts. All three use the SIL Open Font License 1.1, which allows bundling them in an app (including a paid one) as long as the fonts themselves aren't sold on their own.

| File | Font | Used for |
|---|---|---|
| `Cinzel-700.ttf` | Cinzel Bold | Titles |
| `Quicksand-600.ttf`, `Quicksand-700.ttf` | Quicksand | Body text and buttons |
| `Baloo2-700.ttf` | Baloo 2 Bold | Numbers and badges |
