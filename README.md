# Noah's Ark

An interactive Bible story game about Noah's Ark for young kids and older adults, built with Godot 4.7 for the iPhone App Store. It uses the same setup as Backyard Dominoes.

- **Plan and next steps:** [docs/MILESTONE-1.md](docs/MILESTONE-1.md)
- **What the game is:** [docs/VISION.md](docs/VISION.md)
- **Why the project settings are what they are:** [docs/PROJECT-SETTINGS.md](docs/PROJECT-SETTINGS.md)
- **The web prototype this is built from:** [docs/prototype/](docs/prototype/README.md)

Run the tests from Terminal:

```
/Applications/Godot.app/Contents/MacOS/Godot --headless --path ~/NoahsArk -s res://tests/run_tests.gd
```
